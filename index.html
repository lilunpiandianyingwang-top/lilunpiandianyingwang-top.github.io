《持摄影机的人》—— 蒙太奇的终极实验

维尔托夫用一台手持摄影机记录苏联一日，剪辑节奏本身就是理论。片中"摄影机-眼睛"的主张直接影响了后来所有关于电影本体论的讨论。

档案评分：★★★★★ // 正版可核

《公民凯恩》—— 深焦与叙事结构的教科书

格雷格·托兰的深焦摄影让前景后景同时叙事，威尔斯用"玫瑰花蕾"的多视角拼图重构了电影叙事的可能性。每一帧都值得逐格分析。

档案评分：★★★★★ // 正版可核
🎞️

《假面》—— 伯格曼的面部实验

两个女人的面孔逐渐融合，伯格曼把电影最本质的元素——人脸——推到了极限。这部片是"作者论"研究绕不开的案例，建议配合论文一起看。

档案评分：★★★★★ // 正版可核
